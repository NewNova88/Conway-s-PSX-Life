# Conway's PSX Life : Conway's Game Of Life for Sony PlayStation

This is an implementation of the Game Of Life for the PlayStation.

It was initially made under SN Systems original tools, but I readjusted this version for CodeWarrior For PlayStation.
The biggest change is the datafile.asm file.

To compile it yourself you need at least Psy-Q SDK version 4.4.
It should compile under SN Systems ProDG for PlayStation if the assembler allows the datafile.asm changes.

Originally presented at Revision 2024 Demoparty Game Compo category.
